Detailed Description

Structure containing the timeout periods for reading and writing operations.

The timeout values governs the behaviour of SerialPort::read(), SerialPort::write(), SerialPort::asyncRead(), SerialPort::asyncWrite() and subscriptions.

readTimeoutMs is the duration in which sync or async read operations will attempt for, before giving up with a timeout.

writeTimeoutMs is the duration in which sync or async write operations will atempt for, before giving up with a timeout.

listenTimeoutMs is the duration in which the subscription mechanism will attempt to poll for incoming data before polling again.

readMultiplierMs is a multiplier that is multiplied to the number of requested bytes in a sync or async read operation. The product is then added to readTimeoutMs where the sum is the total timeout for the operation.

writeMultiplierMs is a multiplier that is multiplied to the number of requested bytes in a sync or async write operation. The product is then added to writeTimeoutMs where the sum is the total timeout for the operation.

All timeout durations are in milliseconds.
